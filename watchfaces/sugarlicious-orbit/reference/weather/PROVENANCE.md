Samsung artwork: named weather drawables from the user's installed
`com.samsung.android.watch.weather` system application (WeatherWatch.apk).
Google Weather artwork: the pack explicitly labelled "Google Weather" in the
user's installed Ultra 2 reference watchface. No inference is made about ownership
or redistribution permission. Do not publish these imported assets without the
necessary rights. This local user-requested import does not grant a license.

`manifest.json` records exact source paths, byte hashes, original canvas/alpha
bounds and condition/day/night mappings. No generated lookalike icons or image
editing is used. Source APKs remain outside the repository in temporary storage.
