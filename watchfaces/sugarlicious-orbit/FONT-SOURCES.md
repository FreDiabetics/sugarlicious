# Font provenance

Inter Tight variable font, Google Fonts / The Inter Project Authors.

- Source: https://github.com/google/fonts/tree/main/ofl/intertight
- Upstream Git blob: `7d64212163dc15e7f3de5487672668dbde589365`
- Original upstream file: `InterTight[wght].ttf`, renamed resource `inter_tight.ttf`.
- License: SIL Open Font License 1.1, bundled in APK res/raw/inter_tight_ofl.txt
  (raw resource, because Watch Face Push forbids assets/ entries).
- Used at weight 600 to match the reference's Inter Tight Semibold text; no font
  binaries were extracted from the reference application.

Large numeric cardinal glyphs are masked directly from the existing first-party
ApeX dial artwork. The source file is shared unmodified by Gradle resource sync.
