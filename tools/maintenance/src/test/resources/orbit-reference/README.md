# Independent pre-migration Orbit oracle

`watchface.xml` and `strings.xml` were generated by the original
`tools/watchface-assets/generate_orbit.py` and its original Python helper modules
from Sugarlicious commit `2197aa52b5c2a3a7170fa7bfad5b051b27d6bf53` before deletion.
They are comparison fixtures only and are never used as generator inputs.

`OrbitParityTest` compares the complete ordered element tree, attributes and
meaningful text. Only numeric representation is normalized to twelve significant
digits to account for final-bit CPython/libm versus JVM trigonometry differences.
`OrbitGeneratorTest` separately retains all 37 original behavioral tests.
