# Java-engine reference capture

`java-peer.properties` was captured before the final Kotlin core migration, using
the Java engine in the working checkout based on commit
`2197aa52b5c2a3a7170fa7bfad5b051b27d6bf53`, after its mechanically verified Lombok
removal. These are synthetic fixtures, not a person's sensor credentials.

Client private scalars: 1, 2. Peer private scalars: 3, 4. Synthetic password: 1234.
Peer labels are swapped client/server labels. The three 160-byte peer packets
were generated by the old Java Calc/Plugin implementation and successfully
replayed before replacing that implementation. The shared key is independently
checked by the earlier fixed-point derivation reference.

The captured proof nonces are public parts of synthetic proofs. Production RNG
was not seeded, replaced or made deterministic. New proof/signature outputs are
verified, not required to equal independent randomized outputs byte for byte.

`configSha256` hashes every configuration enum name (US-ASCII), a zero byte,
its big-endian four-byte payload length, and the payload in enum order. It locks
the original imported bytes, including legacy nibble-swapped hex parsing.
