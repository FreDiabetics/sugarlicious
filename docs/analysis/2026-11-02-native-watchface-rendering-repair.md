# Native watchface rendering repair

- Removed the failed graph-slot/native-hands opacity experiment. Hands remain native Scene children above the complications; graph slots retain their original bounds and original positional ordering. No extra provider slots. The replacement opacity implementation shares the graph provider text state through WFF Reference while hands remain outside its bounds.
- ApeX original positional order is 7,0,1,2,3,4,5,6; Orbit remains 0,7,2,3,4,5,8,9. Samsung persisted an incorrect TIR binding in ApeX graph slot 11 after the experimental reorder. Temporarily exposing that slot in the editor allowed the native editor to restore the graph binding. Final source makes it fixed again. The new provider envelope is LONG_TEXT with the transparent graph in its monochromatic image and an independent text opacity state. Other providers were restored by the user.
- Progress gradients use native stroked arcs, with explicit circular end caps because Samsung clips SweepGradient at its angular limits. No rectangle shader surfaces or sibling group masks. Shader span is the real bar span, remains stationary with indicators, and does not rotate through a whole circle.
- Orbit round gauge fill direction comes from the forward gauge span rather than its first, reverse-running remainder arc.
- ApeX only outer slots 0..3 have indicators. Slots 4..6 always keep filled/gapped rounded gauges. Outer indicator contour is 5.640898 design units after the requested one-point reduction.
- Imported user ic_tir_inrange.svg; ic_tir vector contains its foreground artwork only. Existing TIR provider and picker references use the updated vector.
- ApeX lower-left provider icon spacing updates both static and live transform coordinates. IOB ranged provider icons enlarge around their original center (32, or 36 lower-left); other providers retain their size. Short-text lower-left icon is 32.

Validation: 57 Python watchface checks passed; Mobile/Wear builds and TherapyComplicationsTest passed. Push validator runs as part of packaging. Mobile, Wear and both face APKs installed. Hardware screenshots confirm full native hands, restored ApeX graph, rounded gradients and correctly oriented lower Orbit gauge.

Center-only transparency now uses a 52x52 design-unit PartDraw Launch and a no-display Activity. It toggles a per-face preference and requests only that graph provider. WFF Reference shares the provider-derived numeric alpha with the native hands Group; no clock images, clipping masks, slot moves or new slots. SmallImage in the LongText envelope was not delivered by the Samsung runtime; supplying the graph via MonochromaticImage restored it on hardware. Normal/ambient images use lossless PNG Icon data. Native previews always use full-opacity hands; live opacity remains independent per face. ApeX now uses WFF4/API36 to support Reference, matching Orbit.

The native graph/control envelope now has two dedicated hidden providers, preserving the public graph providers' SMALL_IMAGE contract. Both new providers are part of event and age refresh planning. Center taps also refresh a previous graph component only if still active during migration. No source/slot order changes.

User confirmed the graph and transparency work.
